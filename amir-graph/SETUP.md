# راه‌اندازی نسخه واقعی امیر گراف

1. پروژه Supabase بسازید و فایل supabase-schema.sql را در SQL Editor اجرا کنید.
2. در Vercel متغیرهای محیطی موجود در .env.example را تنظیم کنید.
3. ZARINPAL_MERCHANT_ID باید شناسه پذیرنده واقعی شما باشد.
4. SITE_URL باید دامنه نهایی HTTPS سایت باشد؛ دامنه callback باید با دامنه ثبت‌شده در زرین‌پال تطابق داشته باشد.
5. ADMIN_PASSWORD را یک رمز طولانی و غیرقابل حدس بگذارید.
6. پروژه Vercel را روی پوشه amir-graph متصل کنید.
7. بعد از Deploy، خرید واقعی از API ایجاد سفارش و سپس زرین‌پال انجام می‌شود.

تا زمانی که کلید Supabase و Merchant ID تنظیم نشده‌اند، پرداخت عمداً غیرفعال می‌ماند و هیچ تراکنش جعلی ایجاد نمی‌شود.
