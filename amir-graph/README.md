# امیر گراف | Amir Graph

فروشگاه آنلاین و استودیو خلاقیت برای محصولات عکس، آتلیه و طراحی هوش مصنوعی، با رابط سه‌بعدی و واکنش‌گرا.

**مالک پروژه:** امیرحسین محمدجانی — برند: امیر گراف

نسخه فعلی یک storefront استاتیک و تعاملی است. برای پرداخت واقعی، دیتابیس، حساب کاربری، پنل مدیریت و تحویل فایل باید بک‌اند/سرویس فروش متصل شود.
