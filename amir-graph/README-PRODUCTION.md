# امیر گراف — نسخه عملیاتی

این پروژه شامل فروشگاه RTL، API محصولات، ثبت سفارش، اتصال زرین‌پال، callback/verify پرداخت، ثبت وضعیت تراکنش و پنل مدیریت سفارش‌هاست.

کلید Service Role و Merchant ID نباید داخل GitHub قرار بگیرند و فقط باید در Environment Variables سرور تنظیم شوند.

برای راه‌اندازی نهایی: پروژه Supabase ساخته شود، schema اجرا شود، متغیرهای محیطی در Vercel تنظیم شوند و پروژه Vercel به پوشه amir-graph متصل شود.
